# 移动端适配设计规范文档

## 一、前言

本文档用于统一本后台系统移动端适配的尺寸、间距、字号和导航交互规范。所有移动端适配必须遵循**不影响现有 PC 端逻辑**的原则，通过响应式样式和独立的移动端组件实现。

---

## 二、断点与布局规范

### 2.1 断点定义

基于 Tailwind CSS 的断点系统：

- **移动端**：`< 768px`（Tailwind：默认样式，不加前缀）
- **平板/PC 起点**：`≥ 768px`（Tailwind：`md:`）
- **大屏 PC**：`≥ 992px`（Tailwind：`lg:`）
- **超大屏 PC**：`≥ 1200px`（Tailwind：`xl:`）

### 2.2 响应式显示/隐藏规则

**核心原则**：PC 端和移动端使用互斥的显示/隐藏类，确保不会同时显示。

- **只在移动端显示**：`flex md:hidden` 或 `block md:hidden`
- **只在 PC 端显示**：`hidden md:flex` 或 `hidden md:block`
- **PC 端原有 DOM 结构**：添加 `hidden md:flex` 或 `hidden md:block` 确保在移动端隐藏
- **移动端新增 DOM**：添加 `flex md:hidden` 或 `block md:hidden` 确保只在移动端显示

### 2.3 布局规范

#### 页面整体
- **宽度**：100%，不设置最大宽度
- **左右安全边距**：`px-4`（16px）
- **顶部安全区域**：适配刘海屏，使用 `pt-safe`（需要自定义 CSS 类，基于 `env(safe-area-inset-top)`）

#### 容器宽度
- **列表页**：左右内边距 `px-4`
- **卡片布局**：移动端使用 `grid-cols-1`，PC 端使用 `grid-cols-2` 或更多
- **弹框/抽屉**：移动端全屏或底部抽屉（高度 60%-80% 屏幕高）

## 三、间距规范

统一使用 Tailwind 的间距 scale：

| 用途 | Tailwind 类 | 实际值 | 说明 |
|------|------------|--------|------|
| 超小间距 | `p-1`, `m-1` | 4px | 图标与文字之间 |
| 小间距 | `p-2`, `m-2` | 8px | 按钮内边距 |
| 标准间距 | `p-3`, `m-3` | 12px | 表单项之间 |
| 大间距（常用） | `p-4`, `m-4` | 16px | 容器内边距、模块间距 |
| 特大间距 | `p-6`, `m-6` | 24px | 大模块之间 |

### 使用建议

- **容器内边距**：默认 `p-4`（16px）
- **表单项之间**：`space-y-3`（12px）
- **按钮内边距**：`py-2 px-4`（上下 8px，左右 16px）
- **列表项间距**：`space-y-1` 或 `space-y-2`

## 四、字体与字号规范

### 4.1 字号定义

| 元素类型 | Tailwind 类 | 实际值 | 行高 | 使用场景 |
|---------|-----------|--------|------|---------|
| 页面主标题 | `text-lg font-semibold` | 18px | `leading-6` (24px) | 页面顶部标题 |
| 模块标题 | `text-base font-medium` | 16px | `leading-6` (24px) | 卡片标题、分组标题 |
| 正文/标签 | `text-sm` | 14px | `leading-5` (20px) | 列表项、表单标签、按钮文字 |
| 辅助说明 | `text-xs text-gray-500` | 12px | `leading-4` (16px) | 提示文字、时间戳 |

### 4.2 行高规范

- **标题**：`leading-6`（24px，1.5 倍行高）
- **正文**：`leading-5`（20px，约 1.43 倍行高）
- **紧凑文本**：`leading-4`（16px，1.33 倍行高）

---

## 五、触控区域与组件尺寸规范

### 5.1 点击热区

**所有可点击元素的最小可点区域：44x44px**

- Tailwind 类：`h-11`（44px）、`min-h-[44px]`、`w-11`（44px）
- 按钮：`min-h-[40px]` 或 `py-2` + `text-sm`
- 图标按钮：`w-10 h-10`（40px）或 `w-11 h-11`（44px）

### 5.2 组件尺寸

#### 按钮
- **高度**：`min-h-[40px]` 或 `h-10`（40px）
- **宽度**：主按钮可用 `w-full`（表单底部、弹窗中）
- **内边距**：`py-2 px-4`（上下 8px，左右 16px）

#### 列表项
- **最小高度**：`min-h-[48px]`（48px）
- **内边距**：`py-3 px-4`（上下 12px，左右 16px）

#### 输入框
- **高度**：`h-10`（40px）或 `h-11`（44px）
- **内边距**：`px-4`（左右 16px）

## 六、颜色与状态规范

### 6.1 颜色使用

- **主色**：`primary`（#0960bd），用于按钮、链接、激活状态
- **文本颜色**：
  - 主要文本：`text-gray-900` 或 `text-gray-700`
  - 次要文本：`text-gray-500`
  - 禁用文本：`text-gray-400` + `opacity-50`

### 6.2 状态样式

- **激活状态**：`text-primary bg-primary/5`（主色文字 + 浅色背景）
- **悬停状态**：`hover:bg-gray-100` 或 `hover:bg-gray-50`
- **禁用状态**：`opacity-50 cursor-not-allowed`

## 七、导航交互规范

### 7.1 顶部一级导航（Header）

#### 移动端布局结构
```
┌─────────────────────────────────┐
│ [☰]  系统名称          [🔔][👤] │
└─────────────────────────────────┘
```

- **左侧**：汉堡菜单按钮（控制侧边栏抽屉）
- **中间**：系统名称/Logo（可点击回首页）
- **右侧**：常用功能入口（消息通知、个人中心）

#### 样式规范
- **高度**：`h-12`（48px）或 `h-14`（56px），全项目统一
- **内边距**：`px-4`（左右 16px）
- **按钮尺寸**：`w-10 h-10`（40px）或 `w-11 h-11`（44px）
- **标题字号**：`text-base font-semibold`（16px）

### 7.2 侧边栏二级菜单（Drawer）

#### 展现形式
- **触发方式**：点击移动端 Header 的汉堡按钮
- **抽屉位置**：左侧拉出
- **宽度**：`w-4/5`（80% 屏幕宽度）或 `max-w-xs`（最大 320px）
- **背景遮罩**：`fixed inset-0 bg-black bg-opacity-40`

#### 菜单层级样式

**一级菜单项**
- **高度**：`min-h-[48px]`
- **内边距**：`px-4`
- **字体**：`text-sm font-semibold`
- **展开箭头**：右侧 `chevron` 图标，旋转表示展开状态

**二级菜单项**
- **缩进**：`pl-8`（左侧内边距 32px）
- **高度**：`min-h-[40px]`
- **字体**：`text-sm`
- **激活状态**：`text-primary bg-primary/5`

#### 交互规范

- **一级菜单点击行为**：
  - 如果一级菜单有对应路由：点击文字区域跳转，点击箭头控制展开/收起
  - 如果一级菜单仅为分组：整行点击即展开/收起
- **展开状态**：默认展开到当前路由所在的一级菜单组
- **点击菜单项后**：自动关闭抽屉

## 八、组件适配原则

### 8.1 核心原则

1. **绝不修改 PC 端逻辑**：所有 PC 端代码保持原样，只添加响应式类
2. **使用响应式类控制显示**：通过 `md:hidden` 和 `hidden md:flex` 实现互斥显示
3. **复用现有数据**：移动端组件复用现有的菜单数据、路由信息、状态管理
4. **统一使用 Tailwind**：所有移动端样式使用 Tailwind 类，避免自定义 CSS

### 8.2 实现步骤

1. **识别 PC 端 DOM**：找到需要隐藏的 PC 端结构
2. **添加响应式隐藏**：在 PC 端容器上添加 `hidden md:flex` 或 `hidden md:block`
3. **创建移动端 DOM**：新建移动端专用结构，添加 `flex md:hidden` 或 `block md:hidden`
4. **复用逻辑**：移动端组件复用现有的 props、computed、methods
5. **测试验证**：确保 PC 端和移动端互不影响

### 8.3 Tailwind 使用约定

#### 显示控制
```vue
<!-- PC 端显示 -->
<div class="hidden md:flex">PC 内容</div>

<!-- 移动端显示 -->
<div class="flex md:hidden">移动端内容</div>
```

#### 间距与字号
- 统一使用 `text-sm`、`px-4`、`py-3`、`space-y-3` 等 Tailwind 类
- 避免使用固定像素值，优先使用 Tailwind scale

#### 容器高度
- 移动端头部统一：`h-12`（48px）或 `h-14`（56px）
- 列表项最小高度：`min-h-[48px]`

## 九、常见场景适配示例

### 9.1 表单适配

```vue
<!-- PC 端：标签在左侧 -->
<n-form-item label="用户名" class="hidden md:block">
  <n-input />
</n-form-item>

<!-- 移动端：标签在上方 -->
<n-form-item label="用户名" label-placement="top" class="block md:hidden">
  <n-input />
</n-form-item>
```

### 9.2 列表适配

```vue
<!-- PC 端：多列网格 -->
<div class="hidden md:grid md:grid-cols-3 md:gap-4">
  <!-- PC 列表项 -->
</div>

<!-- 移动端：单列列表 -->
<div class="grid grid-cols-1 gap-3 md:hidden">
  <!-- 移动端列表项 -->
</div>
```

### 9.3 按钮组适配

```vue
<!-- PC 端：横向排列 -->
<div class="hidden md:flex md:gap-2">
  <n-button>确定</n-button>
  <n-button>取消</n-button>
</div>

<!-- 移动端：纵向排列 -->
<div class="flex flex-col gap-2 md:hidden">
  <n-button class="w-full">确定</n-button>
  <n-button class="w-full">取消</n-button>
</div>
```

## 十、注意事项

1. **测试断点**：在 768px 附近测试，确保切换流畅
2. **性能考虑**：移动端 DOM 虽然隐藏，但仍会渲染，注意性能影响
3. **一致性**：所有移动端组件遵循相同的间距、字号、高度规范
4. **可访问性**：确保移动端交互符合无障碍标准（触控区域 ≥ 44px）
5. **兼容性**：测试不同移动设备浏览器（iOS Safari、Chrome Mobile 等）

## 附录：Tailwind 常用类速查

### 显示控制
- `hidden`：隐藏
- `block`：块级显示
- `flex`：弹性布局
- `md:hidden`：≥768px 时隐藏
- `md:flex`：≥768px 时显示为 flex

### 间距
- `p-4`：内边距 16px
- `px-4`：左右内边距 16px
- `py-3`：上下内边距 12px
- `m-4`：外边距 16px
- `space-y-3`：子元素垂直间距 12px

### 字号
- `text-xs`：12px
- `text-sm`：14px
- `text-base`：16px
- `text-lg`：18px

### 高度
- `h-10`：40px
- `h-11`：44px
- `h-12`：48px
- `min-h-[48px]`：最小高度 48px

### 宽度
- `w-full`：100%
- `w-4/5`：80%
- `max-w-xs`：最大宽度 320px
